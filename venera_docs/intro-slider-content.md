# IntroSlider Content Documentation

This document contains all content and translations for the IntroSlider component.

---

## Overview

The IntroSlider is a vertical Swiper-based carousel that appears between the Hero and Services sections. Each slide features:
- **Left Panel**: Headline with emphasis word + subtitle (with background image)
- **Right Panel**: Paragraph text (with different background image)
- **Stats Bar**: Trust metrics displayed below all slides

---

## Slide Structure

Each slide contains:

| Field | Description | Visibility |
|-------|-------------|------------|
| Subtitle | Small uppercase label above headline | Visible on website |
| Headline Prefix | First part of headline | Visible |
| Headline Emphasis | Emphasized word (italic, golden color) | Visible |
| Headline Suffix | Second line of headline | Visible |
| Paragraph | Descriptive text on right panel | Visible |
| Left Image | Background behind headline | Visible (sepia → color transition) |
| Right Image | Background behind paragraph | Visible (hue-rotate filter) |
| Ken Burns Direction | Animation for left image | Visual effect |
| Overlay Opacity | Darkness of image overlays | Visual effect |

## Translation Notes

### Russian Adaptations
- Headlines restructured for natural Russian grammar
- "Sanctuary of Silent Beauty" → "Святилище Тихой Красоты" (adjective before noun)
- Maintained poetic, contemplative tone
- Medical terminology kept professional yet accessible

### Indonesian Adaptations
- "Sanctuary" kept in English as it's commonly understood and carries brand identity
- Word order adjusted for natural Bahasa Indonesia flow
- Formal "Anda" (you) used for respectful address
- "Janji Kami" (Our Promise) used instead of literal translation

Located in: `sanity/schemas/objects/introSlide.ts`

```
- headlinePrefix (localizedString)
- headlineEmphasis (localizedString)
- headlineSuffix (localizedString)
- subtitle (localizedString)
- paragraph (localizedText)
- leftImage (image with hotspot + alt)
- rightImage (image with hotspot + alt)
- kenBurnsDirection (zoomIn|zoomOut|panLeft|panRight)

```

Located in: `app/components/sections/IntroSlider.tsx`
